When asked for a status, the user wants a single line: the answer first, no "Sure, here's where things stand" preamble.

**Why:** they scan status checks between meetings and read the first line only.

**How to apply:** lead with the fact. "Vendor migration: closed 2026-05-12." Add detail only if asked.
